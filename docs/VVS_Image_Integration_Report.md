## 3. UI ARCHITECTURE & INTERACTIVE COMPONENTS

### 1. Data Store: `src/components/portfolio/portfolio-data.ts`
Centralized, strongly typed repository of all 40 portfolio exemplars with metadata:
- `id`, `title`, `category`, `discipline`, `description`, `image`, `specs`, `rawFilename`, `year`.

### 2. Accessible Lightbox: `src/components/portfolio/PortfolioLightboxModal.tsx`
- Keyboard accessible: `Escape` to close, `ArrowLeft` / `ArrowRight` to cycle between items.
- Backdrop click dismissal and explicit close icon.
- Full metadata display: Category badge, discipline subtitle, high-res image, architectural description, specification pills, and source file reference.
- Accessibility: Focus management, background scroll lock, `aria-modal="true"`.

### 3. Reusable Responsive Grid: `src/components/portfolio/CraftsmanshipGallery.tsx`
- Category filter buttons with dynamic counters (`All (40)`, `Stone Jali & Lattice (3)`, etc.).
- Responsive multi-column layout (1 col mobile, 2 col tablet, 3-4 col desktop).
- Hover micro-interactions with zoom indicators.
- Seamless connection to the Lightbox modal.
